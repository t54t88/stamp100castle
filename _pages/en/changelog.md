# What's New

<br>

### `Latest`
# **Version 3.4**

Added English language support.

#### New Features

- Switch between "Japanese / English / System default" from the Settings screen
- Castle names now show Hepburn-style romanization in English mode
- Search castles by their romanized names

#### Improvements

- Improved the contact/inquiry feature
- Adjusted various layouts
- Minor bug fixes

### **Version 3.3**

Greatly enhanced the photo feature for visit records and the sharing of your progress.

#### New Features

- Register up to 5 photos per castle
- Camera capture / cover image switching / captions / long-press reordering
- Turn a visit record (castle name, stamp, photos, notes) into an image to share on social media and more
- Turn your home-screen progress and per-region progress into an image to share
- A photo gallery view in the Visit History (browse photos of all castles by month)

#### Improvements

- Faster photo display and handling overall (thumbnail caching)
- Tidied up image file management
- Minor fixes

### **Version 3.2**

Added data backup and restore.

#### New Features

- Data backup and restore
- Support for migrating data between iOS and Android

#### Improvements

- Minor fixes

### **Version 3.1**

#### New Features
